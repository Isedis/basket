# Бесконечная Драка

Пиксельная веб-игра про бесконечную прокачку. Открой `index.html` в браузере (рассчитано на телефон).

- Герой дерётся сам; тап по экрану — удар молнии с неба.
- Каждое убийство даёт случайные приросты статов, редкие мобы и вожаки — в разы больше.
- Новые статы открываются бесконечно, каждый следующий сильнее (вес ×N).
- Никаких кнопок улучшений и потолков. Низкое HP = награды хуже.
- Прогресс сохраняется в браузере, есть офлайн-прогресс.
- Сила зон фиксирована: вожак может оказаться сильнее героя — тогда герой отступает и копит силу (шкала готовности, тап по ней — вызвать вожака).
- Тапы: слабое место вожака (×12 урона), заряд ульты, тап-серии и продление комбо.
