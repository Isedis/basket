# Карта проекта 0.15

Начальный вид показывает системы крупными карточками: число сцен, скриптов,
ресурсов, путь к входному файлу и отсутствующие цели ссылок. Стрелки объединяют
реальные статические ссылки между группами; наведение или фокус карточки
подсвечивает её связи. Нажатие открывает файлы группы и её входную сцену.

Второй вид показывает выбранный файл в центре, использующие его файлы слева,
зависимости справа. Карточки содержат тип, имя, путь, вид ссылки и строку.
Нажатие на соседний файл перестраивает граф. При переходе в другую группу
обновляется список файлов; переход по зависимости сбрасывает прежний поиск.
В режиме всех файлов выбор файла не включает скрытый фильтр системы.

Группы — навигационная эвристика по папкам и именам. Названия не являются
подтверждённым описанием игровых обязанностей. Неизвестные папки сохраняют
своё имя. Сам граф берётся из ссылок Godot; отсутствие входящих ссылок не
доказывает неиспользование файла.

Обзор ограничен 24 группами на странице, линии — 96 связями видимых групп.
Число всех межгрупповых связей сообщается отдельно, чтобы отсутствие линий
на странице не означало отсутствие связей вне неё. Файлы показываются по 40,
ссылки выбранного файла — по 8, символы скрипта — по 32. Поиск и номера страниц
разделены для инвентаря и зависимостей. Рисование линий обновляется при изменении
размеров, не требует постоянного опроса и не меняет проект.

Для агента тот же обзор доступен через существующий MCP-инструмент:

```json
{"project_id":"<id>","view":"systems","offset":0,"limit":24}
```

Следующий запрос `system: "<id группы>"` фильтрует файлы. Запрос `file` сохраняет
глобальные входящие/исходящие ссылки, включая другие группы. Кнопка «Для агента»
копирует текущий обзор или страницу связей с ревизией и инструкцией перечитать
исходники перед изменением.

Проверены неизменность индекса, подсчёт ссылок и всех файлов, 61 группа на трёх
страницах, навигация между группами в UI, MCP и обычная работа приложения.
