# Готовая сборка 0.13.0

Основной способ получения приложения — полный `Opora-Windows.zip` в GitHub
Releases. После распаковки запускается `Opora-win32-x64/Opora.exe`; скрипты,
части архива и старая установка не требуются. Release asset собирается из
тех же частей, которые проверены Windows CI, с проверкой общего SHA256.

Для запуска по умолчанию используется `%APPDATA%/opora-desktop`. Прежние
блокировки единственного экземпляра, Chromium-кэши и реестр установок из
`%APPDATA%/opora` не участвуют в новом запуске. Из прежнего профиля однократно
переносятся допустимые пути к последней игре и Claude. Уже существующие
настройки нового профиля не заменяются. Состояние живого отдельного брокера
Claude можно подхватить только после проверки структуры записи и существования
процесса; повреждённая запись игнорируется. Подключение остаётся необязательным
и не блокирует загрузку интерфейса.

Профили, явно выбранные через `--user-data-dir` или `app.setPath`, сохраняются.
Папка игры, `.opora`, работающие старые процессы и прежний профиль не удаляются.

`scripts/portable-smoke.cjs` на одноразовом Windows runner запускает старое
окно с именем `opora`, старым профилем и занятой блокировкой единственного
экземпляра. Затем запускает настоящий опубликованный `Opora.exe` без
подмены точки входа и без переключателя профиля. Проверяет открытие последней
игры, старые пометки и брендбук, запись изменения и повторный запуск,
пока старая копия продолжает работать. Машиночитаемый результат сохранён в
`windows-update-validation-0.13.0.json`.
